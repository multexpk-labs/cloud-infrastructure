# Infrastructure Deployment Checklist

## Design

- [ ] Workload requirements documented
- [ ] Availability target defined
- [ ] Network boundaries defined
- [ ] Storage requirements defined
- [ ] Backup and recovery requirements defined
- [ ] Monitoring requirements defined

## Provisioning

- [ ] OS/image verified
- [ ] Access configured
- [ ] Firewall configured
- [ ] DNS prepared
- [ ] TLS plan prepared
- [ ] Resource limits documented

## Operations

- [ ] Health checks available
- [ ] Logs accessible
- [ ] Metrics available
- [ ] Backups tested
- [ ] Recovery procedure documented
- [ ] Change/rollback process defined
