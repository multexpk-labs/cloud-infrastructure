# Infrastructure Observability

Observability helps answer three questions:

1. Is the system available?
2. Is it performing normally?
3. What changed when it stopped behaving normally?

## Minimum signals

- CPU utilization
- Memory pressure
- Disk capacity
- Disk I/O
- Network traffic
- Service state
- Application errors
- Logs

## Alerting

Alerts should be actionable. Avoid creating alerts that generate noise without a clear response path.
